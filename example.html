Hybrid Widget Example

This page demonstrates the embedded Hybrid Widget. The widget combines chat and voice capabilities in a single floating interface.

👁️ Look for the widget button in the bottom-right corner!

💬 Chat Mode

Powered by Botpress - Full text-based conversation interface

🎙️ Voice Mode

Powered by ElevenLabs - Natural voice conversation agent

🔄 Easy Switching

Toggle between chat and voice modes with a single click

Integration

To add this widget to your website, simply include the following script tag:

<script src="dist/widget.js" defer></script>
